# PDF RAG Chatbot

A Retrieval-Augmented Generation chatbot that allows users to upload PDF documents and ask questions about their content.

## Features
- PDF upload
- PDF text extraction
- Text chunking
- OpenAI embeddings
- ChromaDB vector storage
- Context-based question answering

## Tech Stack
- Python
- Streamlit
- LangChain
- OpenAI
- ChromaDB
- PyMuPDF

## Installation

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
